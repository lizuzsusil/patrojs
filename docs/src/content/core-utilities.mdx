## Core Utilities

The `@patrojs/core` package provides the core Bikram Sambat (BS) date conversion and formatting utilities that power all PatroJS packages. These functions can be used independently in Node.js, React, or any JavaScript/TypeScript application.

### Example

```tsx
import { todayBs, bsToAd } from '@patrojs/core';

const today = todayBs();

console.log(today);
// {
//   year: 2083,
//   month: 4,
//   day: 22
// }

console.log(bsToAd(today));
// "2026-08-06"
```
